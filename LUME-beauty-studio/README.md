# LUMÉ — Beauty Studio

A responsive, editorial-style one-page website concept for a fictional premium beauty studio in Baku.

## Preview
Open `index.html` in a modern browser. No build tools or dependencies are required.

## Included
- `index.html` — semantic page content and sections
- `styles.css` — responsive layout and visual styling
- `script.js` — mobile navigation, review carousel, date validation, and WhatsApp booking request

## Before using for a real business
Replace the sample phone number `994501234567`, address, hours, email and social links with the studio's details. Prices, testimonials and all business information are fictional demo content. The photos load from Unsplash and Google Fonts load from Google Fonts, so those visual assets need an internet connection.

The booking form opens WhatsApp with a prefilled appointment request; it does not store bookings or confirm availability.
